# Photo Grouper

يفحص صور الموبايل بـ ML Kit (أوفلاين)، يجمّع المتشابه، وينسخه في Pictures/PhotoGroups/<اسم المجموعة>.

## طريقة 1: Android Studio
افتح الفولدر ← Sync ← Run (أو Build > Build APK).
الـ APK بيبقى في app/build/outputs/apk/debug/

## طريقة 2: GitHub (من غير تثبيت حاجة)
ارفع المشروع على repo ← تاب Actions ← Build APK ← Run workflow ← نزّل الـ APK من Artifacts.
